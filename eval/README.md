# Evaluation

## Purpose

This directory contains evaluation rubrics, guidelines, and frameworks for conducting systematic qualitative analysis of model responses in FSISP evaluations.

## Focus

FSISP is a **qualitative evaluation framework**, not a quantitative benchmark. The materials in this directory support:

- Structured observation and documentation
- Systematic pattern recognition
- Consistent terminology and description
- Rigorous qualitative analysis

## Contents

### Rubrics
Frameworks for systematic observation and documentation of model responses. Rubrics provide:

- Categories for organizing observations
- Terminology for consistent description
- Guidelines for documentation detail
- Structure for comparative analysis

### Guidelines
Best practices for conducting evaluations:

- How to apply rubrics consistently
- Documentation standards
- Observation techniques
- Analysis approaches

### Frameworks
Conceptual structures for organizing qualitative findings:

- Pattern taxonomies
- Descriptive dimensions
- Comparative frameworks
- Analysis schemas

## Important: What This Is NOT

This directory does NOT contain:

- ❌ Scoring systems or numeric metrics
- ❌ Pass/fail criteria
- ❌ Performance benchmarks
- ❌ Ranking methodologies
- ❌ Predetermined "correct" responses

## Qualitative Evaluation Principles

1. **Descriptive, Not Prescriptive**: Document what is observed, not what "should" be
2. **Neutral Language**: Avoid value judgments and anthropomorphization
3. **Pattern-Focused**: Look for systematic patterns, not isolated instances
4. **Context-Aware**: Consider evaluation conditions and limitations
5. **Transparent**: Document uncertainty and ambiguity

## Using Rubrics

When applying evaluation rubrics:

1. **Read Completely First**: Understand all categories before beginning
2. **Document Observations**: Record what you observe, not interpretations
3. **Use Consistent Terminology**: Apply rubric terms consistently
4. **Note Context**: Record evaluation conditions and constraints
5. **Flag Uncertainty**: Mark ambiguous or unclear observations
6. **Avoid Overgeneralization**: Distinguish patterns from individual instances

## Documentation Standards

Evaluation documentation should:

- Use precise, descriptive language
- Avoid anthropomorphic terms
- Distinguish observation from inference
- Include relevant context
- Note limitations and constraints
- Maintain researcher reflexivity

## Best Practices

1. **Pilot Test**: Test rubrics on sample data before full application
2. **Iterate**: Refine rubrics based on practical use
3. **Document Changes**: Track revisions to rubrics and guidelines
4. **Inter-Rater Reliability**: If multiple researchers, discuss and align understanding
5. **Maintain Neutrality**: Continuously check for bias in observation and documentation
